# Scogen Commercial Strategy

## Philosophy: Segmented Value Pricing

**Core Principle**: Do not sell 'Time'. Sell 'Assets' (Blueprints) and 'Assurance' (Risk Mitigation).

---

## Segment 1: The Vibe Coder / Solo Founder (B2C)

### User Persona
Non-tech founder using Cursor/Replit, or idea-stage entrepreneur.

### Value Proposition
**"Architecture-as-a-Service. Don't let your AI write bad code."**

### Pricing Model: Pay-Per-Download (Asset Sale)

#### Tier 1: The Pitch Packet
**Price**: ₹2,999 ($39)

**Includes**:
- Executive Summary PDF
- Market Fit Analysis
- Rough Cost/Timeline Estimate
- Basic Feature Map

**Target**: Founders needing investor decks

---

#### Tier 2: The Vibe Architect ⭐ (Best Seller)
**Price**: ₹7,999 ($99)

**Includes**:
- Full Technical RFC (The 800-point requirement list)
- Database Schema (SQL/ERD)
- The Context File (`.scogen` / `.cursorrules`) for AI coding tools
- Risk Profile Assessment

**Target**: People building it themselves using AI

---

## Segment 2: The Agency / Dev Shop (B2B SaaS)

### User Persona
Small to mid-sized agencies needing to automate sales and protect margins.

### Value Proposition
**"The Agency Operating System. Liability shield + Shadow Pricing."**

### Pricing Model: Hybrid Subscription + Usage

#### Base Subscription
**₹15,000/month ($199)**

**Includes**:
- 1 Admin Seat (Owner)
- Unlimited 'Draft' Projects
- Access to 'Standard Archetype Library'

#### Usage Fees

**Scope Freeze (Contract Generation)**
- Fee: ₹2,000 per project
- Rationale: Charges only when they close a client

**Dispute Resolution AI**
- Fee: ₹500 per incident
- Rationale: Discourages relying on system for every small argument

---

## Segment 3: The Marketplace Execution (Platform Model)

### User Persona
Clients hiring through Scogen's 'Persona' network.

### Value Proposition
**"End-to-end delivery with escrow protection."**

### Pricing Model: Take Rate (Commission)

**Fee Structure**: 20% - 30% on top of Developer Cost

#### Example Breakdown
```
Developer Payout:    ₹50,000
Platform Fee:        ₹15,000 (30%)
Client Total:        ₹65,000

Fee Breakdown:
- 10% Project Management (AI Monitor)
- 10% Liability Escrow (Held until dispute window closes)
- 10% Scogen Profit
```

---

## Segment 4: Behavioral Pricing (The 'Nuisance' Tax)

### User Persona
Time-wasters, indecisive clients, abusers.

### Value Proposition
**"Filtering noise to maintain system quality."**

### Fees

#### The Entry Ticket
**Price**: ₹500 - ₹5,000 (Adjustable)

**Condition**: Deposit required to start a 'Scoping Session'. Credited back against final purchase. Non-refundable if session abandoned.

**Purpose**: Eliminates window shoppers.

---

#### The Pivot Fee
**Price**: ₹1,000 per Major Iteration

**Condition**: Triggered if user changes >30% of requirements AFTER the 'Draft' phase.

**Purpose**: Stops endless loop scoping.

---

#### The Legal Dump
**Price**: ₹5,000

**Condition**: To retrieve the 'Hash-Stamped' Audio/Evidence file for external legal court use.

**Purpose**: Monetizes the 'Evidence Vault'.

## Strategic Roadmap

### Phase 1: Launch (Months 1-3)
**Focus**: Segment 1 - The Vibe Architect

**Why**:
- No human operations required
- Builds brand and validates Standard Archetypes
- Pure digital product (instant delivery)
- Revenue funds hardware procurement

**Target**: 100 sales @ ₹7,999 = ₹7,99,900 (~₹8L)
- Covers hardware CapEx for Antigravity Rig
- Validates market demand
- Builds archetype library

---

### Phase 2: Scale (Months 4-6)
**Focus**: Segment 2 - Agency SaaS

**Why**:
- Recurring revenue model
- Targets existing agencies (B2B)
- Higher LTV per customer
- Usage fees create margin protection

**Target**: 10 agencies @ ₹15,000/mo = ₹1,50,000 MRR
- Sustainable operations
- Fund persona network development

---

### Phase 3: Platform (Months 7-12)
**Focus**: Segment 3 - Marketplace Execution

**Why**:
- Highest margin (30% take rate)
- End-to-end value chain
- Network effects
- Defensible moat

**Target**: ₹50L in GMV @ 30% = ₹15L revenue
- Full platform economics
- Proven execution capability

## Key Metrics to Track

### Product Metrics
- **Archetype Coverage**: % of requests mapped to existing archetypes (Target: >80%)
- **Margin Guard Triggers**: % of projects locked due to <40% margin
- **Scope Freeze Rate**: % of drafts that convert to frozen scopes

### Commercial Metrics
- **CAC (Customer Acquisition Cost)**: Target <₹2,000 for B2C
- **LTV (Lifetime Value)**: Target >₹50,000 for agencies
- **Churn Rate**: Target <5% monthly for SaaS

### Behavioral Metrics
- **Entry Ticket Conversion**: % who pay deposit and complete
- **Pivot Fee Triggers**: Average iterations per project
- **Dispute Rate**: % of projects requiring resolution

## Competitive Positioning

### vs. Traditional Agencies
- **Faster**: AI-powered scoping (hours vs. weeks)
- **Cheaper**: Asset reuse (80% standard archetypes)
- **Safer**: Frozen scopes + audit trail

### vs. Freelance Platforms
- **Quality**: Pre-vetted archetypes, not random bids
- **Margin Protection**: Shadow pricing prevents race to bottom
- **Liability Shield**: Immutable requirements vault

### vs. AI Coding Tools
- **Architecture**: We sell the blueprint, not just code generation
- **Risk Mitigation**: Constraint registry prevents common failures
- **Execution**: Optional marketplace for full delivery
